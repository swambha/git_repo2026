## This repository is created by Bhairavi Swaminathan.
## This compilation comprises my code utilized for the analysis of both bulk and single-cell RNA-sequencing datasets derived from mouse and human models, codes for wrangling and analyzing datasets combined with clinical information from the TCGA.
## These were used for a wide range of experimental designs:
# Bulk RNAseq- Ligand based activation comparing Control vs Activated
# Bulk RNAseq- Chemical/drug based signal modulation comparing Control vs Inhivition
# Bulk RNAseq- RiboTag comparing Input vs IP and Control vs Experiment (drug)
# Bulk RNAseq- Gene Overexpression comparing Control vs OE
# Bulk RNAseq- Gene KD (shRNA/CRISPR KO) - Comparing Control vs Inhibition
# Bulk RNAseq- Timecourse to track signaling trends
# Single-cell RNAseq - Comparing mouse models with tumor for changes before and after treatment
# Single-cell RNAseq - Comparing mouse models with MASH liver, before and after treatment
# Single-cell RNAseq - Comparing mouse models with disease with/out  CRISPR KO
# Single-cell RNAseq - Comparing mouse models with LPS based inflammation, beforea dn after treatment
# Single-cell RNAseq - Mining publicly available datasets for hypothesis testing or validations
# Data Mining - Wrangling TCGA databases for BRCA, LIHC, UCEC for hypothesis testing, stratified analysis to look for gene expression changes within clinical/phenotypic categories
# Data Mining - Extracting gene expression information and integrating GTEx and TCGA datasets for comparing gene expression patterns betweeb normal vs tumor.
# Machine Learning - Using Caret (R) to extract biomarkers seperating Primary tumor from Metastatic tumors.
